# 🚀 Featured Projects

## 🎧 Real-Time Environmental Sound Classification & Alert System

### `AI/ML` `Deep Learning` `React` `FastAPI` `TensorFlow`

A full-stack real-time environmental sound classification system that processes
microphone audio, classifies sounds and can trigger alerts for potentially
dangerous events.

### 🧠 Architecture

```text
                    🎙️ MICROPHONE
                         │
                         ▼
                 ┌───────────────┐
                 │ Web Audio API │
                 └───────┬───────┘
                         │
                         ▼
                  Audio Processing
                         │
                         ▼
                  Mel Spectrogram
                         │
                         ▼
                ┌────────────────┐
                │ CNN Features   │
                └───────┬────────┘
                        │
                        ▼
                ┌────────────────┐
                │    Bi-GRU      │
                └───────┬────────┘
                        │
                        ▼
                ┌────────────────┐
                │   Attention    │
                └───────┬────────┘
                        │
                        ▼
                 Sound Prediction
                        │
              ┌─────────┴─────────┐
              │                   │
              ▼                   ▼
         Prediction          Danger Check
              │                   │
              ▼                   ▼
        History / UI          🚨 Alert
```

### ✨ Highlights

* 🎙️ Real-time microphone audio processing
* 🌊 Live waveform visualization
* 🎵 Mel-spectrogram feature extraction
* 🧠 CNN + Bi-GRU + Attention architecture
* 🎯 ESC-50 environmental sound classification
* 📊 Classification across 50 sound categories
* ⏱️ Temporal prediction smoothing
* 🚨 Confidence-based danger detection
* 📜 Prediction history timeline
* 🌐 Full-stack web interface
* ⚡ Real-time inference pipeline

### 🛠️ Tech Stack

`Python` `TensorFlow` `Keras` `Librosa` `NumPy`

`FastAPI` `React` `Web Audio API` `Canvas API`
